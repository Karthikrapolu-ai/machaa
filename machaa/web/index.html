A Word document or social post needs a free Gemini key

Search still works with no key. To write a Word document or a social post, open the Machaa folder and edit the file named .env (create it if it is missing). Add one line:

GEMINI_API_KEY= then paste the key.

Get a free key at aistudio.google.com/apikey. Save the file and start Machaa again. On Windows, click the start.bat window, press Ctrl+C, and double-click start.bat.
