A Word document or social post needs a free Gemini key

Search still works with no key. To write a Word document or a social post, open the Machaa folder and edit the file named .env (create it if it is missing). Add one line:

GEMINI_API_KEY= then paste the key.

Get a free key at aistudio.google.com/apikey. Save the file and start Machaa again. On Windows, double-click STOP-MACHAA.bat, then double-click START-MACHAA.bat. The older start.bat still starts the dashboard.

What should Machaa look up?

Machaa can search the web, open one public website, write a Word document, or prepare a social post. A Google robot check is left alone. Purchases, downloads, and your personal Chrome stay off limits.
