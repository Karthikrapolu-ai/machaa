A Word document needs a free Gemini key

Search still works with no key. To write a Word document, open the Machaa folder and edit the file named .env (create it if it is missing). Add one line:

GEMINI_API_KEY= then paste the key.

Get a free key at aistudio.google.com/apikey. Save the file and start Machaa again. On Windows, click the start.bat window, press Ctrl+C, and double-click start.bat.

What should Machaa look up?

Day 1 searches Google or opens one public website, then saves a short report and a screenshot. A Google robot check is left alone and another search source is used. Purchases, downloads, and your personal Chrome stay off limits.
